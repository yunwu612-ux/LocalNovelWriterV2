# LocalNovelWriter V2.5

手机端 V2.5：设备联动基础版 + 性能优化。

- 局域网直连，不需要账号或云服务器
- 手机可开启电脑联动服务，显示局域网地址
- 手机可从电脑读取完整项目
- 手机可把完整项目发送到电脑
- 支持 `.lnw` 完整项目备份/恢复
- 同步前建议保留完整项目备份
- 保留原有写作、章节、人物、世界观、回收站、目标、阅读模式等功能
- 公告栏只保留当前版本 V2.5 公告和永久公告，旧版本公告不再堆积
- 优化首页/小说页切换，移除整页切换动画，减少大页面重组
- 优化统计卡片，移除无必要的缩放动画
- 编辑器自动保存改为 1 秒防抖，减少连续输入时的 JSON 序列化与磁盘写入
- 编辑器自动保存不再每次执行全小说字数统计，离开编辑器时再记录统计数据
- 章节搜索减少重复过滤计算

> 电脑端需要升级到对应的 V1.3 联动版本后，才能直接使用电脑↔手机的局域网同步接口。V2.5 已经把手机端接口准备好。
