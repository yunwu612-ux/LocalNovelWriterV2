# LocalNovelWriter V2.3

完全离线的 Android 本地小说写作工具。

## V2.3
- 章节状态：草稿、修改中、已完成、锁定
- 回收站：小说、章节、分卷可恢复
- 每周写作目标与进度条
- 阅读模式
- 章节拖动排序
- 章节标题/正文搜索
- 小说 TXT/Markdown 导入与 TXT 导出
- 分卷删除（进入回收站）
- 应用自适应图标
- 书籍页导出整本 TXT
- 书籍内导出整本或勾选章节 TXT
- 小说删除确认
- 分卷管理、重命名、章节移动分卷
- 书籍页和书籍内页面动效
- 保留 V2.1 的深色模式、横竖屏、人物、世界资料和字数统计
- 公告栏增加永久更新前备份提醒
- 使用固定 Release 签名密钥构建更新版

包名保持 `com.localnovelwriter.app` 不变。
