# LocalNovelWriter V2.6.1

手机端 V2.6.1：设备联动基础版 + 性能优化。

- 局域网直连，不需要账号或云服务器
- 手机可开启电脑联动服务，显示局域网地址
- 手机可从电脑读取完整项目
- 手机可把完整项目发送到电脑
- 支持 `.lnw` 完整项目备份/恢复
- 同步前建议保留完整项目备份
- 保留原有写作、章节、人物、世界观、回收站、目标、阅读模式等功能
- 公告栏只保留当前版本 V2.6.1 公告和永久公告，旧版本公告不再堆积
- 优化首页/小说页切换，移除整页切换动画，减少大页面重组
- 优化统计卡片，移除无必要的缩放动画
- 编辑器自动保存改为 1 秒防抖，减少连续输入时的 JSON 序列化与磁盘写入
- 编辑器自动保存不再每次执行全小说字数统计，离开编辑器时再记录统计数据
- 章节搜索减少重复过滤计算

> 电脑端需要升级到对应的 V1.3 联动版本后，才能直接使用电脑↔手机的局域网同步接口。V2.6.1 已经把手机端接口准备好。


## V2.6.1
- 优化书籍页进入小说的过渡：不再使用整页 AnimatedContent 同时保留新旧页面，改为单页面轻量淡入 + 小幅横向位移动画，降低首次进入小说时的卡顿和“没有点到”的感觉。
- 小说卡片整张区域均可点击进入，并保留菜单按钮。
- 将全局总字数统计从每次 Compose 重组时的全库扫描改为状态缓存，仅在保存数据时更新。
- 保留 V2.6 的设备联动、左侧隐藏式侧边栏、双向同步与轻量动效。
