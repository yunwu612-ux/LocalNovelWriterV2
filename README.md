# LocalNovelWriter V3.0

手机端 V3.0：书籍、章节、人物、世界观与写作页面全面重绘，并在保留轻量动效的前提下优化性能。

## 页面更新
- 书籍页：重绘为书架式布局，突出小说、章节与人物概览；保留整张卡片点击和更多操作。
- 章节页：重新整理分卷目录、章节卡片、状态与操作入口；保留拖动排序、分卷展开、章节搜索。
- 人物页：资料卡片统一视觉，详情页按基础档案、性格经历、能力关系分组。
- 世界观页：资料卡片统一视觉，详情页按世界概览、历史势力、运行规则分组。
- 写作页：纸张式编辑区域、清晰标题层级、字数状态与阅读模式；保留现有编辑功能。

## 性能与动效
- 保留页面淡入与轻微横向位移动效，不移除动效。
- 避免首页标签切换时叠加两层页面动画。
- 章节字数采用运行时缓存，避免列表每次重组都扫描正文。
- 章节按分卷分组，减少重复过滤。
- 编辑器字数在后台线程计算并做短暂防抖。
- 编辑器自动保存采用后台序列化，并以版本号避免旧保存覆盖新内容。
- 长列表继续使用 LazyColumn 与稳定 key。

## 保留功能
- 手机与电脑局域网联动、双向同步、项目 `.lnw` 导入/导出。
- 本地小说、章节、人物、世界观、分卷、章节状态、回收站、写作目标、阅读模式。
- 公告栏保留永久备份公告与当前 V3.0 公告，不堆积旧版本公告。

> 更新前建议导出完整项目备份。更新时直接安装新 APK，不要先卸载旧版本。
